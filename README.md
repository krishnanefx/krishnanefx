### Tahoe Run · run code inside Obsidian notes

**Released** in Obsidian's community directory · built solo

<a href="https://github.com/krishnanefx/obsidian-tahoe-run"><img src="https://raw.githubusercontent.com/krishnanefx/obsidian-tahoe-run/main/images/debugger.png" alt="Tahoe Run paused at a breakpoint, with the variables view open" width="720" /></a>

- **Problem:** I take my lecture notes in Obsidian, but kept switching to Jupyter or MATLAB to run the code that went with them.
- **What I built:** Python blocks in a note share one live kernel, like a notebook, with breakpoints, stepping and a variables view. MATLAB runs in your own installation; C, C++, Swift and others run as one-off programs.
- **Evidence:** [listed in the community directory](https://community.obsidian.md/plugins/tahoe-run), version 1.6.2. Tested on macOS. Python on iPhone and iPad is in beta and so far tested only in Obsidian's mobile mode on a Mac.

Part of a family I built for my own vault, all in the directory: [Tahoe Code](https://community.obsidian.md/plugins/tahoe-code) (an IDE inside code blocks), [Math](https://community.obsidian.md/plugins/tahoe-math) (answers as you type), [Organize](https://community.obsidian.md/plugins/tahoe-organize), [Intelligence](https://community.obsidian.md/plugins/tahoe-intelligence) and the [Tahoe theme](https://community.obsidian.md/themes/tahoe).

### Lector · a speed reader that respects punctuation

**Released** on the [App Store](https://apps.apple.com/us/app/lector-read-faster/id6807418777?ppid=ef511a4f-0ad6-4e6f-9b32-dc3e99dcce46) · free · iPhone, iOS 17+ · built by me

<a href="https://apps.apple.com/us/app/lector-read-faster/id6807418777?ppid=ef511a4f-0ad6-4e6f-9b32-dc3e99dcce46"><img src="https://is1-ssl.mzstatic.com/image/thumb/PurpleSource211/v4/42/9b/72/429b72fd-3fa4-ee01-2433-cba2cf46b7ab/01-punctuation.png/320x480bb.jpg" alt="Lector on iPhone" width="240" /></a>

- **Problem:** speed readers flash every word for the same time, so a full stop goes by as fast as "the" and sentences fall apart.
- **What I built:** a reader that holds each word longer at the end of a sentence (1.8×) or a clause (1.4×), on a timer that corrects its own drift and never skips a word. Your books stay on your phone.
- **Evidence:** version 1.0.2 on the App Store since September 2026. [Privacy and support](https://github.com/krishnanefx/lector-support).
